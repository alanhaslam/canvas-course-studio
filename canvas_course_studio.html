Back up Course Studio

Create one portable backup containing all custom themes and snippets plus your current Studio selections.

What the backup includes Custom themes, custom snippets, selected theme, selected top-of-page reminder preset, selected bottom-of-page note preset, and common Build preferences.
Where does the backup go? When you export a backup, your browser normally saves the JSON file to its usual Downloads folder unless you have configured the browser to ask where to save each file.
Recommended backup workflow 1. Export your current Course Studio settings. 2. Store the JSON file somewhere you already back up regularly, such as OneDrive, Dropbox, Google Drive, or an institutional network drive. 3. Restore that file later if you need to recover your themes, snippets, or preferences.
Backup filenames include the export date, for example course_studio_backup_2026-11-16.json. Export a fresh copy after meaningful theme or snippet changes you would not want to recreate.
Restore Course Studio

Restore a full Course Studio backup on this browser or another computer. The file is validated before anything is changed.

Restore replaces the current browser's custom themes and custom snippets with the contents of the backup. Built-in presets and built-in snippets are never modified.
About Canvas Course Studio

Canvas Course Studio is an offline tool for creating consistent Canvas pages quickly. It uses simple markup to translate ordinary text into Canvas-ready HTML, from minimally styled Canvas-native structure to more advanced visual layouts.

Canvas Course Studio was developed with ChatGPT as a development tool, but the Studio itself does not connect to ChatGPT, Canvas, or any other online service. It works without an internet connection. User-created content, themes, snippets, preferences, and backups remain local unless the user chooses to copy, export, upload, or share them independently.

How to use this tool
  1. Choose a theme. Use Canvas Native for minimally styled semantic HTML, or choose Light or Structured when you want more visual treatment. Turn on Advanced features only if you want richer layout options.
  2. Write or paste content. Use the Course Studio body and simple markup, or click Load Sample Page to see a working example.
  3. Add page-level extras. Use a top-of-page reminder, bottom-of-page note, footer navigation, or optional contributor details when useful.
  4. Preview and copy. Review the Canvas preview, then copy the generated HTML into Canvas.
  5. Customize when useful. The Themes and Snippets workspaces let you save reusable styles and wording. Export a full backup if you create anything you would hate to lose.

Canvas Course Studio does not publish directly to Canvas. You remain in control of what is copied, exported, or shared.

Tips / FAQ

Tips

  • Use Canvas Native when you want clean semantic HTML that stays close to Canvas defaults.
  • Start with Light when you want restrained visual styling without much additional structure.
  • Use Structured when sections benefit from stronger visual separation.
  • Turn on Advanced features only when you want richer layout options.
  • Preview in Canvas before publishing.
  • Keep headings semantic; don’t choose H3 or H4 just because you like how they look.
  • Use callouts sparingly so they still feel important.
  • Export a full backup after meaningful customization.

FAQ

“Back to Modules” looks like a link, but it won’t know your Canvas course automatically.
Course Studio is offline, so you’ll need to replace the footer URL in Canvas with the correct course Modules link.

Will my custom themes and snippets follow me to another computer/browser?
Not automatically. Use Backup → Export Full Backup, then restore that file on the other browser/computer.

What’s the difference between a callout and a top-of-page reminder?
A callout is part of the page body and goes wherever you insert it. A Top-of-page reminder is a reusable page-level message that Course Studio places near the beginning of the page automatically. The default shows an example “get in touch with questions” reminder.

What’s the difference between a bottom-of-page note and a callout?
A Bottom-of-page note is reusable page-level language—transparency notes, attribution, recurring instructor notes, etc.—that appears near the footer. Callouts belong to the actual instructional content. The default shows an example of instructor transparency about AI use in developing course materials.

Why are some features hidden until I enable Advanced features?
The default interface is meant to stay simple. Advanced mode exposes richer layouts, additional components, and editable preview features when you want them. Advanced layouts use more layered HTML, which can behave unexpectedly when edited directly. Preview edits are also approximate: Import Preview Edits replaces the current Course Studio markup with a translated version of the preview, so review the Course Studio Body afterward.

Can I break anything in Canvas with the HTML?
Usually the worst outcome is that something doesn’t look quite right. Paste into Canvas, preview it there, and adjust as needed. Use the Course Link tool in the Rich Content Editor to add links to other pages in the course. Course Studio doesn’t change your Canvas course directly.

Can I import an existing Canvas page?
Yes, using Import Canvas HTML on the Build tab. It works best with HTML that already resembles Course Studio’s structure; unusual Canvas formatting may not round-trip perfectly.

Should I use H2, H3, and H4 in order?
Yes. Canvas supplies the page H1 through the page title, so Course Studio body content should begin with H2. From there, use H2 → H3 → H4 in order: Section → Subsection → Minor Heading.

Will contributor details carry over to another page?
No. Contributor name and update date are page-specific, so Course Studio starts those fields blank each time you open the tool.

What happens if I import a custom theme or DVC preset?
It is saved locally in that browser. It does not alter the built-in presets.

Where should I keep my Course Studio backup file?
Somewhere you already back up regularly. Export a fresh one after making custom themes or snippets you would not want to recreate.
